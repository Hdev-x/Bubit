# Bubit 사용 가이드

Bubit은 거래소 시세와 차트를 함께 살펴보는 Beta 앱입니다. 현재 외부 접속용 서비스 주소는 없으며, [실행 가이드](SETUP.md)에 따라 로컬 DB·API·Web을 실행한 뒤 사용할 수 있습니다.

## 처음 사용하기

1. PC는 `http://localhost:5174/web/`, Mobile 화면은 `http://localhost:5173/mobile/`을 엽니다. 두 주소는 각각의 개발 서버가 실행 중이어야 합니다.
2. PC에서는 로그인 전에도 마켓을 볼 수 있습니다. 새 계정은 PC의 로그인 → 회원가입 화면에서 만들고, Mobile에서는 해당 계정으로 로그인합니다. 가입 정보는 연결한 로컬 API와 DB에 저장됩니다.
3. 마켓에서 거래소와 종목을 고른 뒤 차트를 엽니다. 시간봉을 바꾸거나 관심종목에 추가할 수 있습니다.
4. 차트에서 지표와 분석·드로잉 도구를 사용합니다. 현재 PC 지표 기능은 관리자 계정으로 제한되어 있습니다.
5. 계좌 조회가 필요한 경우에만 Bitget API key를 연결합니다. 시세·차트 확인을 위해 계좌를 연결할 필요는 없습니다.

브라우저 창에서 Mobile 화면을 열 수 있지만, 이것만으로 실제 휴대전화의 동작까지 검증되는 것은 아닙니다.

## 제공 범위

| 항목 | 현재 지원 |
| --- | --- |
| 시세·차트 | Binance · Bitget · Upbit · Bithumb. 상품·종목 지원 범위는 거래소와 선택한 시장에 따라 다릅니다. |
| 분석 도구 | 지표, SMC·하모닉·파동 분석, 드로잉. Mobile에서 사용 가능하며 PC 지표는 관리자 제한이 있습니다. |
| 계좌 연결 | Bitget만 지원하며 선택 사항입니다. 자산·포지션·미체결 주문 등을 조회합니다. |
| 실제 주문·자동매매 | 이 공개 Beta에는 제공하지 않습니다. |
| 관심종목·차트 설정 | 브라우저에 저장됩니다. 다른 기기나 브라우저로 자동 동기화되지 않습니다. |

Bitget 자격증명을 등록할 때는 조회에 필요한 권한만 사용하세요. 이 앱의 조회 기능에는 주문·출금 권한이 필요하지 않습니다. 보관·삭제 방식은 [데이터 안내](DATA.md)에 설명되어 있습니다.

## 알아둘 점

- 거래소 응답 지연·사용량 제한·네트워크 단절에 따라 데이터가 늦게 갱신되거나 일시적으로 표시되지 않을 수 있습니다.
- PC·Mobile의 빠른 종목/시간봉 전환, 드로잉과 재연결은 실제 기기에서도 계속 확인하는 항목입니다. 자동 테스트가 모든 화면·네트워크 상황을 보장하지는 않습니다.
- 로그아웃은 로그인 토큰을 지웁니다. 관심종목·드로잉·화면 설정과 서버 계정 데이터는 그대로 남습니다.
- 회원 탈퇴와 전체 계정 데이터 내보내기·삭제를 위한 사용자 화면은 아직 제공하지 않습니다.
- Mobile 로그인 화면의 회원가입·소셜·서브계정 버튼과 내 정보 메뉴는 아직 기능이 연결되지 않았습니다. 계정 생성은 PC 화면에서, 로그인은 이메일·비밀번호로 진행하세요.
- PC의 Community 메시지와 인원수는 고정된 UI 샘플입니다. 실제 채팅 송수신 기능은 아직 제공하지 않습니다.
