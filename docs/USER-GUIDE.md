# Bubit 사용 가이드

Bubit은 거래소 시세와 차트를 함께 살펴보는 Beta 앱입니다. [Beta 서비스](https://bubit.ddnsfree.com)를 열거나 [실행 가이드](SETUP.md)에 따라 로컬 DB·API·Web을 실행할 수 있습니다.

## 처음 사용하기

1. PC는 `http://localhost:5174/web/`, Mobile 화면은 `http://localhost:5173/mobile/`을 엽니다. 두 주소는 각각의 개발 서버가 실행 중이어야 합니다.
2. PC·Mobile의 시장·차트는 로그인 없이 볼 수 있습니다. 새 계정은 PC의 로그인 → 회원가입 화면에서 만들고, Mobile의 거래·전략·자산 탭은 해당 계정으로 로그인합니다. 가입 정보는 연결한 API와 DB에 저장됩니다.
3. 마켓에서 거래소와 종목을 고른 뒤 차트를 엽니다. 시간봉을 바꾸거나 관심종목에 추가할 수 있습니다.
4. 차트에서 지표와 분석·드로잉 도구를 사용합니다. 하모닉 등 고급 분석은 PC·Mobile 모두 로그인한 회원에게 제공됩니다.
5. 프로필 아이콘 → 설정에서 프로필·Bitget API·모의투자 메뉴를 선택합니다. 닉네임·프로필 사진을 설정하고, 계좌 조회가 필요한 경우에만 Bitget API key를 연결합니다. 시세·차트 확인을 위해 계좌를 연결할 필요는 없습니다.

브라우저 창에서 Mobile 화면을 열 수 있지만, 이것만으로 실제 휴대전화의 동작까지 검증되는 것은 아닙니다.

## 제공 범위

| 항목 | 현재 지원 |
| --- | --- |
| 시세·차트 | Binance · Bitget · Upbit · Bithumb. 상품·종목 지원 범위는 거래소와 선택한 시장에 따라 다릅니다. |
| 분석 도구 | 지표, SMC·하모닉·파동 분석, 드로잉. PC·Mobile 로그인 회원에게 고급 분석을 제공합니다. |
| 계좌 연결 | Bitget만 지원하며 선택 사항입니다. 자산·포지션·미체결 주문 등을 조회합니다. |
| 모의투자 | Bitget USDT 선물의 시장가·지정가, 롱·숏, 레버리지, 취소·청산·초기화. PC 내 투자는 모의투자 켜짐·주문창 닫힘으로 시작합니다. 제목 아래 캡슐로 전환하고 다른 메뉴에 다녀와도 마지막 선택을 유지합니다. 주문 캡슐을 누르면 Binance 등 다른 차트를 보면서도 Bitget 시세 기준으로 모의 주문할 수 있습니다. 가상 잔고는 10,000 USDT이며 설정 → 모의투자에서 확인 후 초기화합니다. |
| 커뮤니티 | 전체 실시간 채팅 공개 열람, 로그인 후 글·댓글·좋아요·사진 첨부, 본인 글 수정·삭제. 최신순 고정이며 닉네임 옆 날짜·시간을 표시합니다. |
| 실제 주문·자동매매 | 이 공개 Beta에는 제공하지 않습니다. |
| 관심종목·차트 설정 | 브라우저에 저장됩니다. 다른 기기나 브라우저로 자동 동기화되지 않습니다. |

Bitget 자격증명을 등록할 때는 조회에 필요한 권한만 사용하세요. 이 앱의 조회 기능에는 주문·출금 권한이 필요하지 않습니다. 보관·삭제 방식은 [데이터 안내](DATA.md)에 설명되어 있습니다.

## 알아둘 점

- 거래소 응답 지연·사용량 제한·네트워크 단절에 따라 데이터가 늦게 갱신되거나 일시적으로 표시되지 않을 수 있습니다.
- PC·Mobile의 빠른 종목/시간봉 전환, 드로잉과 재연결은 실제 기기에서도 계속 확인하는 항목입니다. 자동 테스트가 모든 화면·네트워크 상황을 보장하지는 않습니다.
- 로그아웃은 로그인 토큰을 지웁니다. 관심종목·드로잉·화면 설정과 서버 계정 데이터는 그대로 남습니다.
- 회원 탈퇴와 전체 계정 데이터 내보내기·삭제를 위한 사용자 화면은 아직 제공하지 않습니다.
- 회원가입은 PC에서 진행하며 2~20자 닉네임을 반드시 입력합니다. 소셜 로그인·서브계정 로그인은 지원하지 않습니다.
- 모의투자는 수수료·펀딩·강제청산·TP/SL을 반영하지 않습니다. 모의 수익을 실제 거래 수익과 동일하게 해석하지 마세요.
- 커뮤니티는 종목을 바꿔도 같은 대화를 유지합니다. 메시지의 `···` 메뉴에서 좋아요·댓글·본인 수정/삭제를 사용합니다. 입력창은 Enter로 전송하고 Shift+Enter로 줄을 바꿉니다.
- PC에서 호가·커뮤니티 표시를 각각 전환할 수 있습니다. 호가만 표시하면 아래에 실제 최근 체결·시장정보가 나타납니다.
- 프로필·첨부 사진은 JPG·PNG, 파일당 최대 1MB입니다. 프로필 사진은 최대 256px PNG로 저장됩니다.
