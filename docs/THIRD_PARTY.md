- [Lightweight Charts 소스와 라이선스](https://github.com/tradingview/lightweight-charts)
- Web 의존성과 정확한 버전: `apps/web/package.json`, `apps/web/package-lock.json`
- API 의존성: `apps/api/build.gradle`
